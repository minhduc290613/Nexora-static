# Imagens do NEXORA - Guia de Adição

Este diretório contém as imagens do website NEXORA. Abaixo está a lista de arquivos de imagem esperados e suas dimensões recomendadas.

## Imagens do Hero Section

1. **laptop-hero.png**
   - Dimensão recomendada: 800x600px ou maior
   - Descrição: Laptop exibido no hero visual
   - Localização: Hero section, lado esquerdo

2. **phone-hero.png**
   - Dimensão recomendada: 300x600px
   - Descrição: Smartphone exibido no hero visual
   - Localização: Hero section, centro

3. **pod-hero.png**
   - Dimensão recomendada: 400x400px
   - Descrição: Dispositivo de áudio/pod exibido no hero visual
   - Localização: Hero section, direita

## Instruções de Upload

1. Coloque todos os arquivos PNG neste diretório (`/images/`)
2. Use os nomes de arquivo exatamente como listados acima
3. Recomenda-se usar PNG com fundo transparente ou JPG conforme necessário
4. As dimensões podem ser ajustadas no CSS se necessário

## Estilo das Imagens

- **Hero images**: Posicionadas absolutamente com transformações de skew e posicionamento flutuante
- **Product images**: Contidas em cards com proporção fixa (quadrada 1:1)
- Todas as imagens têm `object-fit: cover` ou `contain` para melhor apresentação

Após adicionar as imagens, o website exibirá os produtos de forma visual e profissional.
